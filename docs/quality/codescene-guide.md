# CodeScene Integration Guide

CodeScene was not run locally because it requires access to a CodeScene project/account.

## Suggested Setup

1. Connect the GitHub repository to CodeScene.
2. Select `bidmart-listing-query-service` as the analysis scope.
3. Enable analysis for pull requests and main/staging branches.
4. Review these metrics:
   - code health
   - hotspots
   - complexity trends
   - temporal coupling
   - knowledge distribution
5. Attach the CodeScene report screenshot/export to the final assignment evidence.

## Expected Evidence

- Code health score
- hotspot list
- before/after comparison around `ListingQueryService`
- recommendations and accepted/remaining actions

No CodeScene score is claimed in this branch.
